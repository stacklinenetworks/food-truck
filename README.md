# Food Truck Website Template

Reusable static food-truck website template for VS Code and GitHub Pages.

## Customize
Edit `config.js` to change the business name, colors, footer details, links, menu, locations, gallery, reviews, and featured items.

Replace the SVG placeholders in `assets/images/` with the business's real photos when available.

## Run locally
Open `index.html` with VS Code Live Server, or open the file directly in a browser.

## Publish
Upload the contents of this folder to a GitHub repository and enable GitHub Pages.
